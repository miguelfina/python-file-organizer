# 📂 Python File Organizer

Um script em Python que **organiza automaticamente arquivos de uma pasta**, separando-os em subpastas de acordo com o tipo (imagens, documentos, músicas, vídeos e arquivos compactados).

Projeto criado com foco em **automação**, **organização de arquivos** e **prática com Python**.

---

## 🚀 Funcionalidades

- 📁 Seleção da pasta de forma gráfica (interface simples com Tkinter)
- 🖼️ Organização automática de imagens
- 📄 Organização de documentos
- 🎵 Organização de músicas
- 🎬 Organização de vídeos
- 🗜️ Organização de arquivos compactados
- 📂 Criação automática das pastas (caso não existam)

---

## 🛠️ Tecnologias utilizadas

- **Python 3**
- **Tkinter** (seleção gráfica da pasta)
- **OS** (manipulação de arquivos e diretórios)

---

## 📌 Como funciona

1. O programa abre uma janela para o usuário selecionar uma pasta  
2. Todos os arquivos dessa pasta são analisados  
3. Cada arquivo é movido para uma subpasta correspondente ao seu tipo
